# Moka Portfolio

Portfolio site built with [Astro](https://astro.build) from a Figma design.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

Where things go:

- Figma exports (reference only) → `design/mockups/`
- Exact colors, fonts, spacing → `design/design-notes.md`
- Real site images → `src/assets/projects/`
- Project texts → `src/content/projects/<project>.md`
